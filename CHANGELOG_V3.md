# Cambios V3

- Fast path HTTP + fallback Playwright para páginas renderizadas por JavaScript.
- Captura conservadora de respuestas JSON XHR/fetch de la propia página.
- JSON-LD + Microdata + OpenGraph mediante `extruct`.
- Política de identidad: tiendas/marketplaces requieren `EXACT`; conflicto fuerte rechaza fuente.
- Ranking de imágenes por metadata estructurada, galería, tamaño, identidad y ruido visual.
- Extracción de datasheets sin formato `clave: valor`.
- Relaciones por variante/capacidad para lectura, escritura y TBW.
- Descomposición de rangos de temperatura, dimensiones y vibración.
- Garantía separada en valor general, duración, tipo y soporte.
- Notas/condiciones técnicas separadas de especificaciones.
- Vocabulario canónico español/inglés ampliado.
- Inteligencia de plantilla para cabeceras fuera de fila 1, descripciones, IDs `#`, imágenes y datos de vendedor.
- Llenado de columnas de imagen con URLs candidatas puntuadas.
- 9 pruebas unitarias superadas.
