# Excel e identidad

La identidad primaria es MPN / Part Number cuando existe. EAN, UPC o GTIN y marca + modelo sirven como respaldo.

Regla de negocio: `SKU vendedor = Part Number / MPN`.

El valor se deriva de la identidad validada al escribir el Excel y no se busca como dato externo.

Antes de mergear: probar con Excel real y ejecutar regresión.
