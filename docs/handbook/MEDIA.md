# Multimedia

Objetivo: recuperar recursos visuales del producto exacto sin mezclar generaciones ni familias.

Flujo operativo:
1. URL manual u oficial.
2. Descubrimiento por Part Number o modelo.
3. HTML y requests primero.
4. Browser como fallback.
5. Validar identidad, tamaño y calidad antes de aceptar.

Reglas:
- priorizar coincidencia exacta;
- no inflar resultados con otra generación;
- rechazar recursos pequeños, ambiguos o no pertenecientes al producto;
- conservar trazabilidad de fuente y método.

Gate: cobertura útil con contaminación de producto igual a cero.
